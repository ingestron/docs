## Deploy tools

The [deployment templates](/docs/how-to/deploy-through-environments) pin the
tools their stages run: `@microsoft/azure-data-factory-utilities` 1.0.3, the
Databricks CLI v1.23.0, and sqlcmd (Go) v1.10.0. Their check stage installs
`ingestron@2.1.0`, and each GitHub action is pinned to a commit, with its
version beside it.
