`duckdb@1` loads files into tables in a DuckDB database, runs transforms, and
publishes each table as Parquet, with SQL that DuckDB runs on a laptop or
wherever DuckDB runs. List it first, so it names and types the tables:
`packs: [duckdb@1]`, or `packs: [duckdb@1, adf@1]` when ADF lands the files.
The order in `packs` is not the order things run; ADF only copies.
The settings below come from the pack itself.

For a task walkthrough, with the modes, CSV headers and casts explained, use
[DuckDB](/docs/platforms/duckdb). The pack writes `run.sql`, every table in
order, and `tables/`, each table's SQL alone, for each environment. Run
`run.sql` from the project folder with the DuckDB command line; generation
itself runs nothing.
