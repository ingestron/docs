Each download contains a project's synthetic definitions, without generated
files: run `ingestron apply` in its folder to write them. The capabilities
listed below are read from the resolved sample project.

To learn the workflow, follow
[Run your first project on your laptop](/docs/start/first-project), which uses
the `duckdb` starter, or
[Azure Data Factory](/docs/platforms/adf), which uses
`connection-first-adf`. Both are generated and checked from their definition
files.

## Prepared starters

A starter is a complete project for one common situation. Create your own
project from one, answering a few questions:

```sh
ingestron init my-project --template retail
```

For connection-first creation in the CLI or VS Code, follow
[Create a project from a connection](/docs/how-to/start-from-a-template). Each starter is also a [template](/docs/how-to/share-a-template) like the ones you can write
for your organisation.
