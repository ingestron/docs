Ingestron keeps pipeline configuration and data contracts in files you can review
and version in Git. The CLI checks your project and builds it. A provider runs the
flow, and a connector reads the source.

## What you can use today

The published local provider runs ingestion on macOS and Linux. The files connector
reads local CSV, TSV, flat JSON/JSONL and Parquet. Azure Blob reads the same formats
from selected storage objects, including ADLS Gen2 files. The GitHub connector
reads the `issues` stream from GitHub.com. The walkthrough projects issue IDs and
titles into a Parquet file. It includes an explicit review and approval before extraction.

You can also use the CLI to author projects and contracts, build with installed
plugins, or expose project tools to an MCP client. Application developers can use
the separate core package.

Cloud deployment and scheduled runs are not offered by these guides. The
[SQL Server connector](/docs/reference/sql-server) has a local preview path;
check its authentication and live-read limits before using it. See
[supported versions and limits](/docs/reference/releases) before choosing an
execution environment.
