---
title: Install the command and the extension
description: Install the ingestron command, the VS Code extension, or both, to write, plan and generate projects on your computer.
---

You can work with Ingestron from the command line, from VS Code, or both. They
read the same project files and write the same output, so you can switch at any
time. Neither needs a cloud account to generate the examples.

## Set up your interface

<ToolSteps>
<Tool name="CLI">

You need Node.js 22.13 or later.

```sh
npm install -g ingestron
ingestron --help
```

Help should list the available commands. Every page runs the command as
`ingestron`. If the shell says it is not found, see
[Troubleshooting](/docs/troubleshooting#ingestron-command-not-found). To pin
the version a team runs, see
[Upgrade Ingestron and its packs](/docs/how-to/upgrade#choose-the-version-you-run).
The [command line reference](/docs/reference/cli) lists every option.

</Tool>
<Tool name="VS Code">

The extension is not in the Visual Studio Marketplace yet. Build it from
[ingestron/vscode](https://github.com/ingestron/vscode) (Node.js 22.13 or later
and pnpm 10), then install the file it writes:

```sh
git clone https://github.com/ingestron/vscode.git
cd vscode
pnpm install
pnpm package
code --install-extension ingestron.vsix
```

Alternatively, use **Extensions: Install from VSIX…** to select
`ingestron.vsix`. After installation, the Command Palette should include
**Ingestron: New project**. See [VS Code](/docs/tools/vscode) for editor
features.

</Tool>
</ToolSteps>

## Build from source

To change the CLI or its libraries, build them from
[ingestron/ingestron](https://github.com/ingestron/ingestron). You need Node.js
22.13 or later and pnpm 10:

```sh
git clone https://github.com/ingestron/ingestron.git
cd ingestron
pnpm install
pnpm --filter "@ingestron/cli..." build
alias ingestron="node $PWD/packages/cli/dist/main.js"
```

The platform packs, the extension and this site each have their own
repository in the [ingestron organisation](https://github.com/ingestron).

## Verify the workflow

[Run your first project on your laptop](/docs/start/first-project) to confirm that your tool
can create definitions and write local output. Configure source access and
platform deployment only when you are ready to run that output.
