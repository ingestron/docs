<ConnectorNote at="databricks-reading">

With `schema_hints` on, the contract's column types are passed as schema hints,
so the table gets the types you reviewed rather than guessed ones. For CSV with
a header, set `options: { header: true }`.

</ConnectorNote>

<ConnectorNote at="adf-reading">

The connection's `path` is the file share, and each table's `object` is a
folder under that share. The runtime must be self-hosted.

</ConnectorNote>
