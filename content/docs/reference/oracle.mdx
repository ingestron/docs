---
title: "Read Oracle tables"
description: "Use one database connection to read several contracted Oracle tables."
---

Oracle connector 1.0.0 reads selected tables into reviewed Parquet snapshots
through python-oracledb 26.0.1 in thin mode (UPL-1.0 or Apache-2.0); no native database client is needed. The local provider runs
on your machine, so it must be able to reach the database. Use an account with
`SELECT` on the tables and permission to read their column metadata.

```sh
ingestron provider install local@0.4.5
ingestron connector install oracle@1.0.0
```

One connection holds the endpoint and credentials. Each table in an ingestion
flow names its schema and table; its ODCS data contract selects the columns:

```yaml
connections:
  sales:
    package: oracle
    sourceId: sales
    tenantId: training
    settings:
      connection:
        host: db.example.internal
        port: 1521
        service: FREEPDB1
        user: reader
        password:
          $secret:
            env: ORACLE_READER_PASSWORD
flows:
  - apiVersion: ingestron.flow/v1
    kind: ingestion
    id: sales_local
    provider: local
    ingestion:
      connection: sales
      execution: { mode: local }
    tables:
      customers:
        source: { schema: SALES, table: customers }
        contract: { $resolve: ./contracts/customers.odcs.yaml }
```

TLS with certificate verification is the default (`tls: require`); set
`tls: disable` only for a local test database. The password is always a secret
reference, resolved only in the local runtime.

`NUMBER` with scale 0 becomes an integer; other `NUMBER`, `FLOAT`, `BINARY_FLOAT` and `BINARY_DOUBLE` become numbers, with decimals kept exact; `VARCHAR2`, `NVARCHAR2`, `CHAR`, `NCHAR`, `CLOB`, `NCLOB`, `DATE` and `TIMESTAMP` become strings. Schema names are the owning user, usually upper case. Other types fail discovery; leave them out of the contract.

Reads are full snapshots, with no incremental cursor or change capture. A table
larger than one million rows fails rather than being truncated. Every selected
table is read before any record is committed, so a failure in a later table
commits nothing. Errors name a safe code (`DB_CONNECT`, `DB_READ`, `DB_TABLE`)
and never include source values or credentials. For private networks or platform
identities, see [native routes](/docs/concepts/sources).

The connector is marked verified: the shared connector test suite passes against
a real server in a local `gvenzl/oracle-free:23-slim-faststart` container, with synthetic data. It has not
been run against a managed cloud database. See the
[connector guide](https://github.com/ingestron/connectors/blob/oracle-1.0.0/docs/oracle.md).
