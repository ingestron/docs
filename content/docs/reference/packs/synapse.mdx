`synapse@1` shows tables to reporting tools as views in Azure Synapse serverless
SQL: over the files another pack lands, over a transform's query, or over the
files a store pack keeps. For views only, list it first, so it provides the
defaults: `packs: [synapse@1, adf@1]`. The settings below come from the pack
itself.

For a task walkthrough, use [Serve files as SQL](/docs/how-to/serve-files-as-sql).
The pack writes `views.sql` for each environment; run it against the serverless
database when the definitions change. Generation itself creates nothing in Azure.
