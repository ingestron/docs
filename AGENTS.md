# Ingestron docs

Own the docs site and tested downloads for published core, CLI, provider-local and
connectors. Follow CONTRIBUTING.md for the shared plain-language writing style.
Use the current public package contracts. Do not restore old hosted APIs, private
platform guides, roadmap promises or vendored packages.

Use Node 22.12 or newer, pnpm 10.15.0 and scoped codex/ branches. Read the bundled
Next.js documentation before changing app routes or configuration. Run pnpm validate
and the relevant installed example check. Inspect desktop and narrow layouts.
