# Security

Do not put tokens, private repository data or personal information in issues or
example files. For a suspected vulnerability, use GitHub's private vulnerability
reporting for this repository if available. If unavailable, open an issue asking
for a private contact without including vulnerability details.

This site serves documentation and downloadable text examples. It does not accept
credentials or execute projects. The CLI runs on your machine; see the guide on
[secrets and local execution](https://docs.ingestron.io/docs/guides/secrets).
